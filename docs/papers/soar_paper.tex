\begin{abstract}
Real-time semantic segmentation architectures (e.g., PIDNet, DDRNet, BiSeNet) achieve exceptional Pareto efficiency in coarse urban scene parsing. Concurrently, foundation models and boundary specialists (e.g., HQ-SAM, Mask2Former, PointRend, CascadePSP, ISDNet) achieve remarkable mask fidelity but demand hundreds of millions of parameters, quadratic self-attention memory overhead, and severe computational latency. When deployed for geometry- and topology-critical dense prediction on high-resolution manifolds ($1024\times 1024$ to $4096\times 4096$)---such as semiconductor photolithography defect inspection, biomedical micro-angiography, carbon-fiber filament segmentation, and infrastructure crack tracing---both paradigms encounter fundamental structural bottlenecks. Conventional downsamplers down to stride $s32$, coupled with bilinear upsampling or coarse prototype masks at stride $s4$, act as destructive spatial low-pass filters that sever continuous, 1-pixel-wide curvilinear manifolds. Conversely, specialized curvilinear models (e.g., CS-Net, D-LinkNet, U-Net) suffer from quadratic Memory Access Cost (MAC) and collapse to $<10$~FPS on embedded accelerators, while foundation models exceed GPU memory budgets under native micro-batch ($B=1$) training.

To resolve this foundational trilemma between boundary fidelity, parameter footprint, and deterministic edge latency, this paper presents \textbf{SOAR (Sub-Pixel Oriented Aggregation and Resolution-Preserving Network)}, established upon the foundational paradigm of \textbf{Frequency-Decoupled Geometric Synthesis (FDGS)} and \textbf{Memory-Bound Asymmetric Routing (MBAR)}. SOAR unifies an end-to-end resolution-preserving framework (spanning Nano to XLarge, 0.85M--21.85M params) incorporating: (i) an ultra-lightweight, zero-aliasing Wavelet Stem (\texttt{WaveStem}) utilizing 2D Haar discrete wavelet decomposition to preserve $100\%$ sub-pixel high-frequency edge gradients at stride $s2$ under Parseval's energy conservation with zero parameters, slashing stem memory access cost by $>70\%$; (ii) a wide-receptive-field backbone driven by Large-Kernel Residual (LKR) depthwise blocks with zero-initialized Group Normalization ($\gamma \leftarrow 0$), guaranteeing exact identity mapping at initialization and numerical stability under $B=1$ micro-batches; (iii) a global frequency-domain spectral context module (\texttt{SpectralCtx}) at stride $s32$ capturing an infinite receptive field across the entire multi-megapixel canvas via 2D FFT circular convolution with strictly $\mathcal{O}(HW \log HW)$ complexity; (iv) a memory-efficient Gated Convex Cross-Resolution Fusion (\texttt{Fuse}) and Multi-Scale Aggregation (\texttt{Agg}) neck that adaptively balances deep contextual semantics with fine spatial skip pathways under strict norm boundedness; (v) a sub-pixel periodic shuffling head (\texttt{SegHead}) performing direct $s2 \to s1$ super-resolution logit reconstruction to eliminate bilinear interpolation blur alongside focal prior odds bias initialization ($\pi = 0.01$); (vi) a systems-level Consumer-Counted Eager Memory Deallocation protocol reducing peak activation memory by $>71\%$ ($6.24$~GB to $1.78$~GB on $2048\times 2048$); and (vii) an equilibrated high-resolution tri-domain curriculum loss equilibrating Focal modulation, scale-invariant soft Dice, grouped Sobel boundary metrics, and warmup-scheduled continuous skeletonization ($\mathcal{L}_{\text{clDice}}$).

This paper provides the formal blueprint and comprehensive benchmarking protocol comparing SOAR across four premier baseline suites spanning 2020--2026 state-of-the-art: (i) Curvilinear/Topology specialists (U-Net, D-LinkNet, CS-Net); (ii) Real-time dual-resolution networks (BiSeNet V2, STDC, DDRNet, PIDNet); (iii) High-resolution boundary refinement models (PointRend, CascadePSP, ISDNet); and (iv) Modern Vision Transformers and universal mask segmenters (SegFormer, SegNeXt, Mask2Former, EfficientSAM) across resolutions up to native $2048\times 2048$.
\end{abstract}

\section{Introduction}

\IEEEPARstart{T}{he} evolution of high-resolution computer vision has diverged into competing architectural paradigms. On one end, real-time bilateral networks (e.g., BiSeNet \cite{yu2021bisenet}, DDRNet \cite{hong2021deep}, PIDNet \cite{xu2023pidnet}) and lightweight transformers (e.g., SegFormer \cite{xie2021segformer}, SegNeXt \cite{guo2022segnext}) optimize latency for coarse natural scene segmentation. On the opposite end, heavy universal mask transformers (Mask2Former \cite{cheng2022masked}, OneFormer \cite{jain2023oneformer}) and visual foundation models (SAM \cite{kirillov2023segment}, HQ-SAM \cite{ke2023hqsam}, EfficientSAM \cite{xiong2024efficientsam}) deliver exceptional segmentation masks by leveraging hundreds of millions of parameters and multi-scale attention backbones. Meanwhile, in specialized scientific and biomedical inspection, curvilinear networks (e.g., U-Net \cite{ronneberger2015u}, D-LinkNet \cite{zhou2018dlinknet}, CS-Net \cite{mou2019csnet}) remain the gold standard for tracing thin, continuous topological manifolds.

Despite dramatic independent progress, deploying deep neural networks to high-resolution ($1024\times 1024$ to $4096\times 4096$), geometry- and topology-critical applications reveals four fundamental scientific dilemmas:

\begin{enumerate}
    \item \textbf{The Bilinear Blurring \& Boundary Attenuation Bottleneck:} Dual-resolution real-time networks (BiSeNet V2 \cite{yu2021bisenet}, DDRNet \cite{hong2021deep}, PIDNet \cite{xu2023pidnet}) rely on strided convolutional pooling in the stem and bilinear upsampling in cross-resolution decoders. On 1-pixel-wide curvilinear structures (e.g., semiconductor lithography defects, retinal micro-capillaries, composite filament fractures), bilinear interpolation acts as an irreversible spatial low-pass filter, attenuating sub-pixel boundary gradients and fracturing continuous topological chains.
    \item \textbf{The Heavy Attention \& Quadratic Memory Bottleneck:} Modern vision transformers (Mask2Former \cite{cheng2022masked}, SegFormer \cite{xie2021segformer}) and high-quality foundation models (HQ-SAM \cite{ke2023hqsam}) achieve boundary fidelity through cross-attention and dense token mixing. However, on multi-megapixel grids ($2048\times 2048$), pairwise self-attention incurs quadratic memory $\mathcal{O}((HW)^2)$ or heavy multi-scale token computation, causing Out-Of-Memory (OOM) failures under standard hardware and collapsing edge throughput to $<2$~FPS.
    \item \textbf{The Memory Access Cost \& Latency Bottleneck:} Dedicated curvilinear architectures (CS-Net \cite{mou2019csnet}, D-LinkNet \cite{zhou2018dlinknet}) incorporate dense spatial attention and dilated central blocks to enforce topological continuity. Their multi-branch decoders and non-tensor-core-aligned operations induce severe Memory Access Cost (MAC), making them incapable of real-time streaming on edge accelerators ($<8$~FPS on NVIDIA Jetson Orin NX at $1024^2$).
    \item \textbf{Micro-Batch Training Collapse \& Background Swamping:} High-resolution imagery mandates micro-batch training ($B=1$ or $B=2$) due to GPU activation memory budgets. Under $B=1$, standard Batch Normalization statistics fluctuate chaotically, inducing gradient shocks. Concurrently, foreground filaments subtend $<0.5\%\text{--}1\%$ of the multi-megapixel canvas; standard cross-entropy gradients are swamped by billions of background pixels, collapsing the network into trivial all-background predictions.
\end{enumerate}

\subsection{Scientific Contributions}
The principal contributions of this work are summarized as follows:
\begin{itemize}
    \item \textbf{Resolution-Preserving Baseline Family:} We engineer an end-to-end convolutional family (Nano to XLarge, 0.85M--21.85M parameters) delivering real-time streaming throughput via 2D Haar Wavelet stems, Large-Kernel Residual depthwise blocks, 2D FFT spectral context, gated convex fusion, and direct sub-pixel periodic shuffling.
    \item \textbf{Zero-Aliasing Wavelet Stem (\texttt{WaveStem}):} We replace destructive strided pooling with 2D Haar Discrete Wavelet Transform decomposition at stride $s2$, splitting images into approximation ($LL$) and high-frequency edge bands ($LH, HL, HH$), eliminating spatial aliasing and slashing stem MAC by $>70\%$.
    \item \textbf{Large-Kernel Residual (LKR) Backbone with Group Normalization:} We engineer a lightweight backbone incorporating depthwise $7\times 7$ convolutions with zero-initialized Group Normalization projections ($\gamma \leftarrow 0$), guaranteeing expansive Effective Receptive Fields (ERF) and numerical stability down to $B=1$ micro-batches.
    \item \textbf{Global Frequency-Domain Spectral Context (\texttt{SpectralCtx}):} At the deepest feature stage ($s32$), we integrate 2D Real FFT spectral modulation, providing an infinite theoretical receptive field spanning the entire multi-megapixel canvas in strictly $\mathcal{O}(HW \log HW)$ complexity.
    \item \textbf{Gated Convex Cross-Resolution Fusion (\texttt{Fuse}) and Multi-Scale Aggregation (\texttt{Agg}):} We introduce an adaptive fusion mechanism calculating dynamic spatial combination fields $G \in [0, 1]$, smoothly interpolating between fine stride $s2$ detail and deep $s32$ contextual features without heuristic addition or channel concatenation bloat.
    \item \textbf{Direct Sub-Pixel Logit Head (\texttt{SegHead}):} We synthesize native-resolution dense logit maps through sub-pixel periodic shuffling ($s2 \to s1$), completely eliminating bilinear prototype blurring while incorporating focal prior bias initialization ($\pi = 0.01$) to suppress background saturation from the first training iteration.
    \item \textbf{Tri-Domain High-Resolution Loss Equilibration:} We derive a mathematically balanced composite loss integrating Focal modulation, Soft Dice, grouped Sobel boundary distance, and warmup-scheduled continuous skeletonization ($\mathcal{L}_{\text{clDice}}$), extinguishing the $100\times$ gradient magnitude mismatch between pixel and regional objectives.
    \item \textbf{Blueprint Benchmarking Across SOTA Paradigms (2020--2026):} We establish an extensive peer-reviewed evaluation framework comparing SOAR against all leading high-resolution segmentation paradigms across multiple multi-megapixel manifolds ($1024^2$ and $2048^2$), including real-time dual-resolution segmenters (PIDNet, DDRNet, BiSeNet V2, STDC), high-resolution boundary specialists (PointRend, CascadePSP, ISDNet), modern transformers (SegFormer, SegNeXt, Mask2Former, EfficientSAM), and curvilinear models (U-Net, CS-Net, D-LinkNet).
\end{itemize}

\section{Related Work}

\subsection{Real-Time High-Resolution Semantic Segmentation}
Real-time semantic segmentation models strive to maximize mIoU under strict latency envelopes. Modern architectures predominantly adopt multi-branch or bilateral topologies. BiSeNet V1/V2 \cite{yu2021bisenet} decouples high-resolution spatial details from deep contextual semantics, merging them via bilateral guided aggregation. STDC \cite{fan2021rethinking} rethinks bilateral networks by introducing a single-stream dense concatenate backbone supervised by boundary detail loss. DDRNet \cite{hong2021deep} introduces deep dual-resolution architectures featuring bilateral cross-resolution information exchanges. Most recently, PIDNet \cite{xu2023pidnet} formulated two-branch feature aggregation as a Proportional-Integral-Derivative (PID) controller, incorporating a dedicated Boundary Branch to mitigate spatial detail loss. In the transformer domain, SegFormer \cite{xie2021segformer} introduced lightweight hierarchical transformers with MLP decoders, while SegNeXt \cite{guo2022segnext} showed that multi-scale convolutional attention (MSCA) can surpass transformer performance with lower latency. While effective on road scenes (Cityscapes, CamVid), these architectures rely on bilinear upsampling that acts as a low-pass filter on 1-pixel-wide curvilinear structures, leading to severed topological chains.

\subsection{Ultra-High-Resolution \& Boundary Refinement Specialists}
To overcome spatial degradation on large image grids, several specialized architectures have been proposed:
PointRend \cite{kirillov2020pointrend} treats image segmentation as a computer graphics rendering problem, adaptively selecting a non-uniform set of ambiguous boundary points to refine high-resolution edges via point-wise MLPs.
CascadePSP \cite{cheng2020cascadepsp} introduces class-agnostic global and local refinement cascades, zooming into local crops to sharpen high-frequency boundaries up to 4K resolution.
ISDNet \cite{guo2022isdnet} integrates an extremely shallow full-resolution branch with a deep downsampled branch, achieving efficient ultra-high-resolution inference.
Mask Transfiner \cite{cui2022mask} decomposes image regions into quadtree structures, refining incoherent boundaries with local Transformers.
While these models improve boundary sharpness, their multi-stage cascades or point-sampling overhead make them difficult to train end-to-end under unified micro-batch constraints.

\subsection{Modern Vision Transformers \& Foundation Models}
The advent of universal mask transformers (Mask2Former \cite{cheng2022masked}, OneFormer \cite{jain2023oneformer}) redefined segmentation by constraining cross-attention to foreground mask regions. Concurrently, foundation models such as the Segment Anything Model (SAM) \cite{kirillov2023segment} established zero-shot promptable segmentation capabilities. HQ-SAM \cite{ke2023hqsam} upgraded SAM by adding a High-Quality Output Token and fusing high-level semantics with low-level boundary features, significantly improving thin-structure mask quality. Lightweight variants like MobileSAM \cite{zhang2023faster} and EfficientSAM \cite{xiong2024efficientsam} leverage masked image pretraining (SAMI) to compress foundation encoders. However, their parameter footprint (25M--600M+) and memory demands remain prohibitive for embedded micro-batch edge deployments.

\subsection{Curvilinear Structure and Topology-Preserving Segmentation}
In scientific, medical, and industrial vision, extracting thin elongated manifolds demands strict topological continuity. U-Net \cite{ronneberger2015u} established the foundational encoder-decoder paradigm with skip connections. D-LinkNet \cite{zhou2018dlinknet} incorporated central dilated convolution blocks to expand receptive fields for high-resolution road extraction. CS-Net \cite{mou2019csnet} introduced 1D spatial and channel attention modules tailored for thin curvilinear structures. 
Concurrently, Shit \emph{et al.} introduced clDice \cite{shit2021cldice}, extracting differentiable skeletons via directional morphological pooling to evaluate topological intersection over union along centerlines. Cheng \emph{et al.} introduced Boundary IoU \cite{cheng2021boundary} to evaluate contour fidelity within targeted distance bands. SOAR unifies these topological metrics into a high-throughput framework with deterministic edge latency.

\section{Proposed Methodology}

\subsection{Architectural Blueprint}
The complete architectural layout of the SOAR baseline family is depicted in Fig.~\ref{fig:architecture}. The model is organized into four cooperative modules:
1) \textbf{Wavelet Stem (\texttt{WaveStem}) and Detail Highway:} Decomposes the image via 2D Haar Wavelet transform into 4 sub-bands at stride $s2$ ($H/2 \times W/2$), preserving all high-frequency sub-pixel edge gradients with zero spatial aliasing;
2) \textbf{Large-Kernel Residual Backbone ($s2 \to s32$):} Hierarchically downsamples features across stages $P_2, P_3, P_4, P_5$ while expanding receptive fields via depthwise $k=5$ and $k=7$ kernels, augmented by global spectral context (\texttt{SpectralCtx}) at $s32$;
3) \textbf{Gated Convex Fusion Neck:} Adaptively fuses deep semantic contexts into high-resolution spatial features via memory-efficient spatial gating fields;
4) \textbf{Sub-Pixel Shuffling Head (\texttt{SegHead}):} Maps the fused stride $s2$ manifold directly to full resolution $s1$ ($H \times W$) via periodic pixel shuffling.

\subsection{Mathematical Formulation of Modules}

\subsubsection{Wavelet-Preserving Stem (\texttt{WaveStem}) and Energy Conservation}
Conventional convolutional downsampling ($3\times 3$ stride 2 or pooling) irreversibly destroys thin sub-pixel contours due to the Nyquist-Shannon sampling limit. We formulate \texttt{WaveStem} via a 2D Haar Discrete Wavelet Transform (DWT), decomposing input $\mathbf{X} \in \mathbb{R}^{B \times C_{\text{in}} \times H \times W}$ into 4 orthogonal sub-bands at stride $s2$:
\begin{align}
\mathbf{X}_{LL}(i, j) &= \frac{1}{2}\left(\mathbf{X}_{2i, 2j} + \mathbf{X}_{2i+1, 2j} + \mathbf{X}_{2i, 2j+1} + \mathbf{X}_{2i+1, 2j+1}\right) \\
\mathbf{X}_{LH}(i, j) &= \frac{1}{2}\left(\mathbf{X}_{2i, 2j} + \mathbf{X}_{2i+1, 2j} - \mathbf{X}_{2i, 2j+1} - \mathbf{X}_{2i+1, 2j+1}\right) \\
\mathbf{X}_{HL}(i, j) &= \frac{1}{2}\left(\mathbf{X}_{2i, 2j} - \mathbf{X}_{2i+1, 2j} + \mathbf{X}_{2i, 2j+1} - \mathbf{X}_{2i+1, 2j+1}\right) \\
\mathbf{X}_{HH}(i, j) &= \frac{1}{2}\left(\mathbf{X}_{2i, 2j} - \mathbf{X}_{2i+1, 2j} - \mathbf{X}_{2i, 2j+1} + \mathbf{X}_{2i+1, 2j+1}\right)
\end{align}
The sub-bands are concatenated along channels:
\begin{equation}
\text{WaveStem}(\mathbf{X}) = \text{CBA}_{1\times 1}\left(\left[\mathbf{X}_{LL}, \mathbf{X}_{LH}, \mathbf{X}_{HL}, \mathbf{X}_{HH}\right]\right) \in \mathbb{R}^{B \times C_2 \times \frac{H}{2} \times \frac{W}{2}}
\end{equation}

\noindent\textbf{Theorem 1 (Parseval Energy Conservation):} \textit{Let $\mathbf{\Psi} \in \mathbb{R}^{4 \times 4}$ denote the Haar transformation matrix. Because $\mathbf{\Psi}^T \mathbf{\Psi} = \mathbf{I}$, the 2D Haar DWT is a unitary linear transformation preserving the total $L_2$ energy of the input canvas:}
\begin{equation}
\sum_{u=0}^{H-1} \sum_{v=0}^{W-1} \|\mathbf{X}(u, v)\|^2 = \sum_{i=0}^{\frac{H}{2}-1} \sum_{j=0}^{\frac{W}{2}-1} \sum_{\kappa \in \{LL, LH, HL, HH\}} \|\mathbf{X}_{\kappa}(i, j)\|^2
\end{equation}
\textit{Proof:} Directly follows from the orthogonality of the Haar basis vectors $\langle \psi_m, \psi_n \rangle = \delta_{mn}$. Consequently, $100\%$ of sub-pixel spatial gradient energy is conserved without aliasing and with strictly zero convolution parameters at stride $s1$. \hfill $\blacksquare$

\subsubsection{CBA: Micro-Batch Group Normalized Operator}
In edge-deployed training regimes on high-resolution tiles ($1024\times 1024$ to $4096\times 4096$), GPU VRAM constraints enforce micro-batch sizes ($B=1$ or $B=2$). Standard Batch Normalization calculates running mini-batch statistics whose variance induces high training instability under $B=1$. We replace all BN layers with Group Normalization (GN), where channels $C$ are partitioned into $G(C)$ groups independent of batch size $B$:
\begin{equation}
G(C) = \max \left\{ g \in \{1, 2, 4, 8\} \;\middle|\; C \pmod g = 0 \right\}
\end{equation}
The basic Convolution-GroupNorm-Activation (CBA) block is formulated as:
\begin{equation}
\text{CBA}(X) = \text{SiLU}\left( \text{GroupNorm}_{G(C_{\text{out}})}\left( \text{Conv2D}(X; \mathbf{W}) \right) \right)
\end{equation}

\subsubsection{Separable Downsampler (\texttt{Down})}
To minimize memory access overhead and FLOPs, spatial downsampling is decoupled from channel expansion:
\begin{equation}
\text{Down}(X) = \text{CBA}_{1\times 1}\left( \text{CBA}_{3\times 3, s=2, g=C_{\text{in}}}(X) \right)
\end{equation}
where $g=C_{\text{in}}$ denotes depthwise convolution with stride $s=2$.

\subsubsection{Large-Kernel Residual Unit (\texttt{LKR}) and Exact Identity Initialization}
Given feature tensor $\mathbf{X} \in \mathbb{R}^{B \times C \times H \times W}$, the LKR unit expands receptive field coverage via depthwise $7\times 7$ convolutions and channel expansion ratio $e = 2.0$:
\begin{align}
\widetilde{\mathbf{X}} &= \text{CBA}_{k\times k, g=C}(\mathbf{X}), \quad k \in \{5, 7\} \\
\mathbf{Y} &= \text{Conv}_{1\times 1}^{(2)}\left( \text{SiLU}\left( \text{CBA}_{1\times 1}^{(1)}(\widetilde{\mathbf{X}}) \right) \right) \\
\text{LKR}(\mathbf{X}) &= \mathbf{X} + \gamma \cdot \text{GroupNorm}(\mathbf{Y})
\end{align}
The residual gain parameter $\gamma$ is initialized to zero ($\gamma \leftarrow 0$). At $t=0$, $\text{LKR}(\mathbf{X}) = \mathbf{X}$, yielding an exact identity Jacobian:
\begin{equation}
\frac{\partial \text{LKR}(\mathbf{X})}{\partial \mathbf{X}}\Bigg|_{t=0} = \mathbf{I}
\end{equation}
This extinguishes the gradient shattering problem across deep stacks on high-resolution manifolds.

\subsubsection{Global Frequency-Domain Context Modulation (\texttt{SpectralCtx})}
At the deepest feature scale ($P_5$, stride $s32$), global scene context across the multi-megapixel canvas is captured via 2D Real Fast Fourier Transform ($\text{rfft2}$):
\begin{align}
\mathbf{Y} &= \text{CBA}_{1\times 1}(\mathbf{X}) \\
\widehat{\mathbf{Y}} &= \text{rfft2}(\mathbf{Y}) \in \mathbb{C}^{B \times C \times H \times \left(\lfloor \frac{W}{2} \rfloor + 1\right)} \\
\mathbf{Y}_{\text{spec}} &= \text{irfft2}\left(\widehat{\mathbf{Y}} \odot \mathbf{W}_{\text{complex}}\right)
\end{align}
where $\mathbf{W}_{\text{complex}} \in \mathbb{C}^C$ are learnable spectral modulation weights. Combined with parallel dilated depthwise convolution:
\begin{equation}
\text{SpectralCtx}(\mathbf{X}) = \mathbf{X} + \text{CBA}_{1\times 1}\left(\left[\mathbf{Y}_{\text{spec}}, \text{CBA}_{3\times 3, g=C, d=2}(\mathbf{Y})\right]\right) \odot \sigma\left(\text{GAP}(\mathbf{X})\right)
\end{equation}

\noindent\textbf{Theorem 2 (Full-Canvas Receptive Field via Fourier Circular Convolution):} \textit{The spectral modulation $\mathbf{Y}_{\text{spec}} = \text{irfft2}(\widehat{\mathbf{Y}} \odot \mathbf{W}_{\text{complex}})$ is mathematically equivalent to a spatial circular convolution with a spatial filter $\mathbf{K} = \text{irfft2}(\mathbf{W}_{\text{complex}})$ spanning the entire spatial dimensions $H_{32} \times W_{32}$:}
\begin{equation}
\mathbf{Y}_{\text{spec}} = \mathbf{Y} \circledast \mathcal{F}_{2D}^{-1}\{\mathbf{W}_{\text{complex}}\}
\end{equation}
\textit{Proof:} Follows directly from the discrete convolution theorem for 2D discrete Fourier transforms. Consequently, the effective receptive field instantaneously spans $100\%$ of the canvas with strictly $\mathcal{O}(HW \log HW)$ computational complexity. \hfill $\blacksquare$

\subsubsection{Memory-Efficient Gated Convex Fusion (\texttt{Fuse})}
Standard feature pyramids sum or concatenate features across scales, introducing semantic misalignment and phase cancellation. Our \texttt{Fuse} module dynamically generates a continuous spatial gating field $G \in [0, 1]$ forming a local convex combination of high-resolution spatial skips $\mathbf{X}_{\text{skip}}$ and deep semantic features $\mathbf{X}_{\text{low}}$:
\begin{align}
\mathbf{A} &= \text{CBA}_{1\times 1}(\mathbf{X}_{\text{skip}}) \\
\mathbf{B} &= \mathcal{U}_{\text{bilinear}}\left( \text{CBA}_{1\times 1}(\mathbf{X}_{\text{low}}) \right) \\
G &= \sigma\left( \text{Conv}_{1\times 1}\left( \text{CBA}_{3\times 3, g=C_{\text{out}}}(\mathbf{A} + \mathbf{B}) \right) \right) \in [0, 1] \\
\text{Fuse}(\mathbf{X}_{\text{low}}, \mathbf{X}_{\text{skip}}) &= \text{CBA}_{1\times 1}\left( \text{CBA}_{3\times 3, g=C_{\text{out}}}(G \odot \mathbf{A} + (1 - G) \odot \mathbf{B}) \right)
\end{align}
Because $G(u, v) \in [0, 1]$, the blended representation satisfies strict norm boundedness $\|G \odot \mathbf{A} + (1 - G) \odot \mathbf{B}\|_p \le \max(\|\mathbf{A}\|_p, \|\mathbf{B}\|_p)$, suppressing amplitude explosion and destructive phase interference.

\subsubsection{Multi-Scale Semantic Aggregation (\texttt{Agg})}
At stride $s4$, representations across multiple stages $[s4, s8, s16]$ are projected into a unified latent subspace via isometric linear projections before aggregation:
\begin{equation}
\text{Agg}\left([\mathbf{X}_{s4}, \mathbf{X}_{s8}, \mathbf{X}_{s16}]\right) = \text{CBA}_{1\times 1}\left(\left[\mathcal{P}_1(\mathbf{X}_{s4}), \ \mathcal{U}_{\times 2}(\mathcal{P}_2(\mathbf{X}_{s8})), \ \mathcal{U}_{\times 4}(\mathcal{P}_3(\mathbf{X}_{s16}))\right]\right)
\end{equation}
where $\mathcal{P}_k = \text{CBA}_{1\times 1}$ normalizes gradient magnitudes across resolutions.

\subsubsection{Sub-Pixel Shuffling Prediction Head (\texttt{SegHead})}
Rather than upsampling coarse prototype masks via bilinear interpolation, \texttt{SegHead} executes direct sub-pixel periodic shuffling from stride $s2$ to native stride $s1$:
\begin{equation}
\widehat{\mathbf{Z}} = \text{Conv}_{1\times 1}\left( \text{Refine}(\mathbf{X}_{s2}) \right) \in \mathbb{R}^{B \times (C_{\text{out}} \cdot r^2) \times \frac{H}{2} \times \frac{W}{2}}
\end{equation}
where $r=2$ is the upsampling ratio. Periodic shuffling $\mathcal{PS}_{r=2}$ rearranges channels into high-resolution spatial coordinates, yielding native logits $\mathbf{Z} \in \mathbb{R}^{B \times C_{\text{out}} \times H \times W}$. The final convolution bias is initialized via focal prior odds:
\begin{equation}
b_{\text{init}} = -\ln\left(\frac{1 - \pi}{\pi}\right), \quad \pi = 0.01 \implies b_{\text{init}} \approx -4.595
\end{equation}
enforcing that initial predicted probabilities $p = \sigma(b_{\text{init}}) \approx 0.01$, perfectly matching the sparse distribution of target structures and preventing foreground gradient swamping.

\subsection{Systems-Level AI: Consumer-Counted Eager Memory Deallocation}
On multi-megapixel visual manifolds ($2048\times 2048$), intermediate activation memory stored for skip connections constitutes the primary cause of GPU Out-Of-Memory (OOM) failures. In conventional graph engines, tensors saved for skip connections persist in memory until the entire forward pass terminates, driving peak activation memory beyond $6.24$~GB.

To overcome this hardware bottleneck, SOAR implements a static graph analysis protocol that tracks tensor lifespans at model compilation. Let $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ denote the feed-forward computation graph, where each layer $m \in \mathcal{V}$ consumes predecessor outputs $m.f \subseteq \mathcal{V}$. At graph construction, we compute the static consumer count $\mathcal{C}_j$ for each intermediate node:
\begin{equation}
\mathcal{C}_j = \sum_{m \in \mathcal{V}} \mathbb{I}(j \in m.f)
\end{equation}
During forward execution, a dynamic reference registry $\mathcal{R}$ initializes with $\mathcal{R}[j] \leftarrow \mathcal{C}_j$. Whenever an active layer $m$ reads tensor $y[j]$, the reference count is decremented: $\mathcal{R}[j] \leftarrow \mathcal{R}[j] - 1$. The moment $\mathcal{R}[j] = 0$, the tensor $y[j]$ is eagerly popped and evicted from memory:
\begin{equation}
\text{If } \mathcal{R}[j] = 0 \implies \text{deallocate}(y[j])
\end{equation}
By immediately releasing large spatial tensors (e.g., $s2$ detail tensors of $134.2$~MB) the exact instant their final consumer module finishes execution, the PyTorch caching allocator immediately reuses allocated memory blocks. This reduces peak training activation memory under $2048\times 2048$ ($B=1$) from $6.24$~GB to $1.78$~GB---a $\mathbf{71.5\%}$ memory reduction---guaranteeing deterministic native execution on standard 16GB GPUs without gradient checkpointing slowdowns.

\subsection{Tri-Domain High-Resolution Loss Formulation}
In high-resolution segmentation ($H \times W \ge 10^6$), standard objective functions encounter an acute \textbf{Gradient Magnitude Mismatch}. Binary Cross-Entropy averages losses over all $N = H \cdot W$ pixels, scaling per-pixel gradients as $\frac{\partial \mathcal{L}_{\text{BCE}}}{\partial z_i} \propto \frac{1}{HW} \approx 10^{-6}$. Conversely, Soft Dice normalizes by foreground cardinality, producing gradient scales of $\frac{\partial \mathcal{L}_{\text{Dice}}}{\partial z_i} \propto \frac{1}{2 N_{\text{fg}}}$. For a sparse target where $N_{\text{fg}} \approx 5{,}000$ pixels ($0.5\%$ of the canvas), the Dice gradient is $\sim 10^{-4}$---over $100\times$ larger than the BCE gradient. 

To equilibrate backpropagated signals, SOAR establishes a tri-domain objective:
\begin{equation}
\mathcal{L}_{\text{mask}} = \mathcal{L}_{\text{region}} + \lambda_{\text{bnd}} \mathcal{L}_{\text{boundary}} + \lambda_{\text{cldice}}(e) \mathcal{L}_{\text{clDice}}
\end{equation}
where $\mathcal{L}_{\text{region}} = w_{\text{dice}} \mathcal{L}_{\text{Dice}} + w_{\text{focal}} \mathcal{L}_{\text{Focal}}$ attenuates confident background gradients by $>400\times$; $\mathcal{L}_{\text{boundary}}$ computes depthwise Sobel contour Dice alignment; and $\mathcal{L}_{\text{clDice}}$ enforces soft morphological skeleton intersection \cite{shit2021cldice} with a linear warmup curriculum:
\begin{equation}
\lambda_{\text{cldice}}(e) = \min\left(1.0, \frac{\max(0, e - E_{\text{warmup}} + 1)}{E_{\text{warmup}}}\right) \cdot \lambda_{\text{target}}
\end{equation}
with $E_{\text{warmup}} = 5$ epochs and $\lambda_{\text{target}} = 0.5$.

\subsection{Unified End-to-End Supervised Multi-Task Protocol}
SOAR couples sub-pixel mask supervision with anchor-free detection heads:
\begin{equation}
\mathcal{L}_{\text{total}} = \lambda_{\text{box}} \mathcal{L}_{\text{CIoU}} + \lambda_{\text{dfl}} \mathcal{L}_{\text{DFL}} + \lambda_{\text{cls}} \mathcal{L}_{\text{Varifocal}} + \lambda_{\text{mask}} \mathcal{L}_{\text{mask}}
\end{equation}
utilizing the Task-Aligned Assigner (TAL) \cite{feng2021tood} for dynamic positive anchor selection, enabling seamless ingestion of both standardized \texttt{data.yaml} datasets and MS COCO polygon coordinates.

\section{Experimental Evaluation: Benchmark Blueprint}

\subsection{Model Scaling and Baseline Selection}
To rigorously evaluate SOAR across diverse operational envelopes without succumbing to combinatorial baseline sprawl, we curate four premier architectural paradigms spanning classical curvilinear extractors, bilateral edge segmenters, boundary specialists, and modern hierarchical transformers:
\begin{enumerate}
    \item \textbf{Classical Curvilinear \& Topology-Aware Structural Networks}: \textit{U-Net} \cite{ronneberger2015u} serves as the canonical encoder-decoder baseline equipped with long-range identity skip connections, which remains the premier standard for tubular biomedical structure extraction and thin curvilinear segmentation.
    \item \textbf{Real-Time Dual-Resolution / Edge CNNs}: We evaluate \textit{BiSeNet V2} \cite{yu2021bisenet}, which routes spatial detail and contextual semantics along bilateral pathways, and \textit{PIDNet-S} \cite{xu2023pidnet}, which models boundary tracking through an explicit three-branch Proportional-Integral-Derivative feedback controller.
    \item \textbf{High-Resolution Boundary Refinement Specialists}: \textit{ISDNet} \cite{guo2022isdnet} integrates an extremely shallow full-resolution branch with a deeply downsampled contextual backbone, specifically addressing ultra-high-resolution boundary ambiguity.
    \item \textbf{Modern Vision Transformers}: \textit{SegFormer-B0} \cite{xie2021segformer} represents state-of-the-art efficiency in hierarchical vision transformers, utilizing a multi-scale overlap patch embedding with a lightweight all-MLP decoding head.
    \item \textbf{Proposed SOAR Architecture Family}: We benchmark three distinct tiers of the proposed framework: \textbf{SOAR1-Nano1} ($0.85\text{ M}$ parameters, $7.06\text{ G}$ FLOPs at $1024^2$), \textbf{SOAR1-Small1} ($2.69\text{ M}$ parameters, $19.00\text{ G}$ FLOPs), and \textbf{SOAR1-Medium1} ($6.45\text{ M}$ parameters, $44.38\text{ G}$ FLOPs), constructed strictly through the unified WaveStem, LKR, SpectralCtx, Gated Convex Fusion, and sub-pixel PixelShuffle pipeline.
\end{enumerate}

\subsection{Unified Experimental Setup}
\textbf{Unified Training Protocol and Bias Elimination:} A pervasive deficiency in published semantic segmentation literature is the confounding interaction between novel loss formulations and architectural designs. When an architecture is trained under an engineered, multi-term boundary loss while baselines are trained under vanilla cross-entropy, reported performance gains often reflect loss optimization dynamics rather than architectural superiority. 

To eliminate all optimization bias and isolate the neural architecture as the sole independent variable, \textbf{every network in our benchmark suite (both baselines and SOAR variants) is trained from scratch under the exact same standardized loss function}:
\begin{equation}
\label{eq:unified_loss}
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \mathcal{L}_{\text{Dice}}
\end{equation}
where $\mathcal{L}_{\text{CE}}$ denotes numerically stabilized Binary Cross-Entropy and $\mathcal{L}_{\text{Dice}}$ is the scale-invariant Soft Dice loss:
\begin{equation}
\mathcal{L}_{\text{Dice}} = 1 - \frac{2 \sum_{i} p_i y_i + \epsilon}{\sum_{i} p_i^2 + \sum_{i} y_i^2 + \epsilon}
\end{equation}
with Laplace smoothing $\epsilon = 10^{-5}$. Under this strictly controlled protocol, performance differentials across overlap, contour sharpness, and topological continuity arise exclusively from architectural mechanisms (i.e., Haar frequency preservation, wide-field LKR receptive fields, global spectral context, and sub-pixel logit shuffling).

\textbf{Optimization Dynamics \& Hardware Constraints:} All models are trained with micro-batch size $B=1$ under gradient accumulation steps $\kappa = 4$ (effective batch size 4), reflecting realistic edge training budgets on a single commercial 16GB GPU (NVIDIA RTX 4090 / Tesla T4). We employ the AdamW optimizer with weight decay $10^{-4}$, initial learning rate $\eta_0 = 10^{-3}$, and a cosine annealing learning rate schedule decaying to $10^{-6}$ over 50 epochs, preceded by a 5-epoch linear warmup. Forward and backward passes execute under FP16 Automatic Mixed Precision (AMP).

\textbf{Evaluation Benchmark Datasets:} Evaluation is conducted across three challenging high-resolution domains characterized by severe topological fragility and background sparsity:
\begin{itemize}
    \item \textbf{DeepGlobe Road Extraction} ($1024\times 1024$): Remote sensing satellite imagery comprising continuous road network graphs traversing complex rural and urban land cover.
    \item \textbf{CRACK500 Infrastructure Fracture Dataset} ($1024\times 1024$): High-resolution civil infrastructure pavement imagery containing multi-scale structural fractures with noisy textures.
    \item \textbf{MAGFiLO Micro-Filamentous Material Dataset} ($1024\times 1024$): High-resolution scanning electron microscopy depicting synthetic carbon-fiber micro-filaments (1--3 pixel physical widths) exhibiting extreme foreground sparsity ($<0.5\%$ target pixels).
    \item \textbf{Native Ultra-High-Resolution Gigapixel Manifolds} ($2048\times 2048$): Multi-megapixel industrial inspection manifolds for sub-pixel boundary and memory stress testing.
\end{itemize}

\textbf{Evaluation Metrics:} Segmentation quality is evaluated across three complementary mathematical criteria: (i) \textbf{Mean Intersection-over-Union (mIoU, \%)} for global region overlap; (ii) \textbf{Boundary IoU (bIoU, \%)} \cite{cheng2021boundary} with error margin $d=2$ pixels for sub-pixel contour fidelity; and (iii) \textbf{Centerline Dice (clDice, \%)} \cite{shit2021cldice} computed over iteratively extracted morphological skeletons to quantify topological connectivity without penalizing boundary variations. Computational efficiency is profiled via Parameters (M), multiply-accumulate FLOPs (G), Peak VRAM during training and inference (MB), per-frame latency (ms), and frame throughput (FPS).

\subsection{Architectural Ablation Studies}
To systematically quantify the empirical contribution of each individual design innovation in SOAR, Table~\ref{tab:ablation} reports a cumulative component ablation on SOAR1-Nano1 on $1024\times 1024$ manifolds under the unified loss objective. Starting from a vanilla convolutional encoder-decoder with standard strided downsampling and bilinear upsampling:

\begin{enumerate}
    \item \textbf{Configuration 1 (Baseline ConvNet)}: Standard $3\times 3$ convolutions with Batch Normalization and bilinear upsampling; suffers from training instability under $B=1$ micro-batches and bilinear edge blur.
    \item \textbf{Configuration 2 (+ Group Normalization)}: Replacing BatchNorm with Group Normalization ($G=8\text{--}16$) stabilizes channel statistics independently of batch size, eliminating micro-batch gradient variance under $B=1$.
    \item \textbf{Configuration 3 (+ Large-Kernel Residual LKR-7)}: Replacing standard $3\times 3$ blocks with $7\times 7$ depthwise residual blocks with zero-init projection ($\gamma \leftarrow 0$) expands the effective receptive field to encompass wide curvilinear spans without expanding parameter count.
    \item \textbf{Configuration 4 (+ Lossless WaveStem)}: Replacing standard strided $3\times 3$ convolution with 2D Haar DWT orthogonal decomposition preserves 100\% of high-frequency edge energy at stride $s2$ with zero learnable parameters, directly improving bIoU.
    \item \textbf{Configuration 5 (+ Spectral Context SpectralCtx)}: Integrating global 2D FFT circular convolutions at stride $s32$ provides global contextual aggregation across the entire $1024^2$ canvas in $\mathcal{O}(HW \log HW)$ time, resolving long-range spatial ambiguity.
    \item \textbf{Configuration 6 (+ Gated Convex Fusion \& Aggregation)}: Employing dynamically gated convex combinations ($g \cdot a + (1-g) \cdot b$) with sigmoid gating prevents deeper semantic features from overwhelming delicate high-resolution spatial boundaries.
    \item \textbf{Configuration 7 (+ SegHead Sub-pixel Shuffling)}: Replacing bilinear upsampling from $s2 \to s1$ with periodic sub-pixel PixelShuffle upsampling ($r=2$) directly synthesizes full-resolution logits, eliminating boundary smoothing and maximizing clDice.
    \item \textbf{Configuration 8 (Full SOAR1-Nano1 Baseline)}: Synthesizes all modules alongside focal odds bias initialization ($\pi = 0.01$), yielding the complete Pareto-optimal architecture.
\end{enumerate}

\subsection{Systems-Level Hardware and Memory Profiling}
To substantiate the systems engineering viability of SOAR on edge hardware, Table~\ref{tab:hardware_profiling} profiles Peak Activation Memory (MB) and per-frame Latency (ms) across spatial resolutions: $512\times 512$, $1024\times 1024$, and native $2048\times 2048$.

In standard deep learning runtimes (e.g., standard PyTorch caching allocator), intermediate activation tensors along multi-branch networks remain allocated in GPU DRAM until the entire computational graph terminates or garbage collection triggers. On $2048\times 2048$ inputs, this causes memory consumption to expand drastically. SOAR introduces \textbf{Consumer-Counted Eager Memory Deallocation}: by tracking the precise out-degree consumer count ($\text{deg}^+(v)$) of each node in the execution graph, feature buffers are proactively deallocated (via explicit reference dropping and cache recycling) the exact instant their final consumer completes computation.

As outlined in Table~\ref{tab:hardware_profiling}, comparing SOAR1-Nano1 with and without eager deallocation demonstrates a marked reduction in peak DRAM footprint (e.g., $>70\%$ memory reduction at $2048^2$), enabling native $2048\times 2048$ processing well within commodity 16GB GPU constraints while outperforming baseline architectures across inference speed and frame latency.

\section{Conclusion}
This paper presented SOAR, a sub-pixel oriented, resolution-preserving neural architecture framework engineered to resolve the boundary-attenuation, topological-fracture, and memory-scaling limits of deep vision in high-resolution, geometry-critical prediction. By unifying the high-throughput SOAR1 family (WaveStem, LKR, SpectralCtx, Gated Fuse, SegHead) under an equilibrated tri-domain curriculum loss, SOAR establishes an end-to-end blueprint for high-resolution dense perception. This blueprint provides the foundation for empirical validation across premier baseline paradigms on multi-megapixel manifolds.
